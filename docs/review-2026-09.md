## Auto-learn (PR #16, lead-built per the A4 fallback)

After a paste lands, `EditWatcher` remembers the span (pid, AX element, UTF-16 range, exact text,
40-char before-anchor, timestamp). At the first of {next dictation keypress, frontmost-app change,
90 s} it re-reads a 200/400-char window, re-anchors the span **exactly once** (ambiguous anchor →
discard), runs a word-level LCS, and decides per substitution:

- **Case-only or all-lowercase fix → dictionary term immediately** (except stoplist / ≤2 letters).
- **Gibberish-from → replacement immediately**; **real-word-from → `corrections-pending.json`,
  promoted only on the second sighting** (sounds-alike gate).
- **Undo loop**: if the owner edits X back toward the previously-pasted Y, the stored Y→X rule is
  removed — reverts never compound.
- **Guards**: skipped entirely when AX is untrusted, the field is secure, or focus moved
  (`.copiedAppChanged`); ≤2 substitutions per paste; ≥50 % of changed pasted words must be fixes
  (deviation from the brief's >30 % rewrite bar — its own test table requires learning at 33 %/40 %;
  documented in code); pure insertions/deletions/punctuation ignored.
- **Never-clobber writes**: `dictionary.json` and the pending file are read-modify-write with
  last-good fallbacks; a malformed file is never overwritten.
- **UI**: "Learn from my corrections" toggle (default on), plus "Learned: x → y" and "Undo learned
  correction" menu rows.

Tests: all 13 required rows (junk→immediate, real-word→pending-then-promote, case→term, undo X→Y,
stoplist, ≤2-char skip, punct-only skip, pluralizations, rewrite guard, multi-sub, ambiguous anchor,
empty anchor, span shifted by user edits above it) — 193/0 on its branch, 277/0 merged.

**Known limits**: needs the AX grant to do anything (degrades to inert); reads only the focused
text field's window — Electron/web views that don't expose `AXStringForRange` silently no-op;
the learner is deliberately conservative (pending-gate + rewrite guard) so it prefers learning
nothing to learning wrong.

## Top 5 before handing it to strangers

1. **Measure release→paste on a real M1** — if the ANE doesn't beat ~100 ms on no-pause tails, the
   §0 target needs the streaming decode path (`--streaming 640` already benched at 66–83 ms finish
   on this VM). Biggest open speed question.
2. **The ~100 ms tail drop (known 1)** — an async `MicRecorder.stop()` draining the tap queue is
   the one remaining "clip the user's last syllable" path. Effort L; decide whether it ships.
3. **Distribution** — Developer ID signing + notarization + DMG + auto-update (Sparkle), or stay
   `install.sh`-only (now tag-pinned). Owner call; no code written.
4. **Grant onboarding** — auto-learn and AX paths are inert without Accessibility; the first-run
   flow should say so plainly. Also: hotkey remap for keyboards without a Right Option (A2-09).
5. **Known-3 forced-cut word splits + A3-13 quoted fillers** — the two remaining "changes what
   the user said" edges; both need owner sign-off on the trade-off before fixing.
